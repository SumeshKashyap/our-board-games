# Installing Our Board Games — a guide for family

Our Board Games isn't in the Play Store, so it's installed from a file. It takes about 3 minutes and only needs to be done once.
It works on Android phones and tablets (Android 8 or newer).

## 1. Get the app file

**Either** open this link on the phone or tablet:

> **https://github.com/SumeshKashyap/our-board-games/releases/latest**

and tap the file ending in **`.apk`** (for example `OurBoardGames-v2.0.0.apk`) under **Assets**.

**Or** open the `.apk` file that was sent to you on WhatsApp (this "family edition" includes our family photos).

The file is about 90 MB, so Wi-Fi is best.

## 2. Allow the install

When you open the file, Android may say *"For your security, your phone is not allowed to install unknown apps from this source"*.

1. Tap **Settings** in that message.
2. Turn on **Allow from this source**.
3. Press the **Back** button. You return to the install screen.

## 3. Install

1. Tap **Install**.
2. If **Google Play Protect** says it doesn't recognise the app, tap **More details → Install anyway**.
   (It says this for any app that isn't from the Play Store.)
3. Tap **Open**. You will find **Our Board Games** (a white die on a green circle) with your other apps.

## 4. First time in the app

1. Family photos appear for a few seconds. Then type **your name** and tap **Continue**.
2. Choose a **level** from 1 (Beginner) to 5 (Expert). You can change it later.
3. Choose a game: **Chess**, **Checkers** or **Ludo**. Each has its own menu (play, puzzles, lessons).
4. Optional: **My photos → Add photos** to add your own pictures to the opening screen.

Everyone in the house can have their own name on the same device: tap **Switch player** in the menu.

## Updating to a new version

Do the same steps 1–3 with the new file. Android asks **"Do you want to update this app?"**: tap **Update**.
Your name, level, games and photos are kept.

## If something goes wrong

| Problem | What to do |
|---|---|
| "App not installed" | An older copy installed from a different source is in the way. Uninstall *Our Board Games*, then install again. |
| Can't find the downloaded file | Open the **Files** app → **Downloads**. |
| The file opens as text or a zip | Download it again, and make sure the name ends in `.apk`. |
| The pieces look small | Turn the tablet sideways, or use **Settings → Display → Font size** to make text bigger. |
